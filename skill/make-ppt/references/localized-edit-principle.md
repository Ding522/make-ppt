# localized-edit-principle.md — mandatory reading before modifying an existing deck

When the user modifies a presentation generated by this skill, interpret the request
**literally and minimally**. A local edit is not permission to redesign.

Before editing, read `references/cost-control-workflow.md` and classify the request.
Only `small-localized` changes proceed without an impact artifact. For every other
classification, write `presentation/edit-impact.md` from
`templates/edit-impact-template.md` before touching maintained source.

Example request: 「第 7 頁標題左邊加上中華電信 icon，其他內容不要更動」
→ Add the icon. Nudge the title right only if geometrically required. Nothing else.

## Rules

1. Preserve all unaffected content.
2. Preserve all unaffected wording — do not rewrite text for style.
3. Preserve the existing visual form.
4. Preserve the existing layout.
5. Preserve unaffected element positions.
6. Preserve screenshots.
7. Preserve screenshot crop settings.
8. Preserve colors.
9. Preserve typography.
10. Preserve diagram structure.
11. Change only explicitly requested elements.
12. Do not opportunistically "improve" another part of the slide.
13. Do not create a new layout.
14. Do not reinterpret a local edit as a redesign request.
15. If movement is technically required to accommodate the change, move the minimum
    number of affected elements by the minimum necessary amount.

Allowed for 「標題左邊加 icon」: add the icon; shift the title slightly right if
required. Not allowed: replacing the title, moving the architecture diagram, changing
orange to blue, rewriting the takeaway, introducing new cards, reorganizing the slide.

Editing Constraints recorded per slide in `outline.md` (e.g. "preserve the 40/60
composition") bind these edits too.

## Mechanics

- Edit the maintained source (`presentation/src/…`), never the .pptx binary — the
  deck must stay regenerable.
- If the requested change alters content/argument, also update the corresponding
  Per-Slide Specification in `outline.md` so outline and deck stay in sync.
- Regenerate `presentation/src/build.py` with a working Python 3 interpreter, using
  the bundled Bash or PowerShell Python wrapper when interpreter discovery is needed.
- Re-render only affected slides; refresh the contact sheet.
- Verify in the re-render that untouched slides are byte-for-byte-intent identical
  (spot-check one neighboring slide).
- Do not opportunistically convert a legacy text-box grid into a native table during
  an unrelated edit. Convert it only when the user explicitly requests a table fix or
  requests a full deck rebuild.
- Return to Narrative Fork when the narrative direction changes and the replacement
  direction is not precise. When it is precise, rewrite only `outline.md`. In both
  cases, re-present the outline checkpoint before builder work.
- Apply the authoritative full rebuild triggers and gate order from
  `references/cost-control-workflow.md`. Treat `full-rebuild-candidate` as an
  additional flag; when narrative restructure also applies, both gates must pass
  before builder work.
